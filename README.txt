HOW TO EDIT
1. Open this folder in VS Code (free: code.visualstudio.com).
2. Edit index.html: text, projects, certifications, links. Look for <!-- EDIT --> comments.
3. Edit style.css: colors are at the top (--g is the green). 
4. Replace images/profile.jpg with another photo (same name) to change the picture.
5. To preview: double-click index.html. Install the "Live Server" extension for auto-refresh.
6. To publish free: upload the folder to GitHub Pages, Netlify or Vercel.
